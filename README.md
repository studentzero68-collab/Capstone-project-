# Zero — Where Every Journey Begins

> Airbnb-style property booking platform built for the Zaio Full Stack Developer Bootcamp Capstone.
> Stack: React (Vite) · Node.js · Express · MongoDB · JWT

---

## How to Run

### Frontend (React app)
```bash
# From the project root folder
npm install
npm run dev
```
Opens at → http://localhost:5173

### Backend (Node.js API)
```bash
# From the server/ folder
cd server
npm install
npm run dev
```
Runs at → http://localhost:5000

> The app works without the backend running — it falls back to demo data automatically.

│   │     reservationRoutes.js   → /api/reservations/*

## API Endpoints (Backend)

### Users
| Method | URL                    | Access  | Description          |
|--------|------------------------|---------|----------------------|
| POST   | /api/users/register    | Public  | Create account       |
| POST   | /api/users/login       | Public  | Login, returns JWT   |
| GET    | /api/users/me          | Private | Get my profile       |

### Accommodations
| Method | URL                         | Access       | Description          |
|--------|-----------------------------|--------------|----------------------|
| GET    | /api/accommodations         | Public       | Get all listings     |
| GET    | /api/accommodations/:id     | Public       | Get one listing      |
| POST   | /api/accommodations         | Host / Admin | Create listing       |
| PUT    | /api/accommodations/:id     | Host / Admin | Update listing       |
| DELETE | /api/accommodations/:id     | Host / Admin | Delete listing       |

### Reservations
| Method | URL                         | Access  | Description               |
|--------|-----------------------------|---------|---------------------------|
| POST   | /api/reservations           | Private | Make a booking            |
| GET    | /api/reservations/user      | Private | My bookings               |
| GET    | /api/reservations/host      | Private | Bookings on my properties |
| DELETE | /api/reservations/:id       | Private | Cancel a booking          |
